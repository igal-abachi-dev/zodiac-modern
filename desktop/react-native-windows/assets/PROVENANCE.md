# Local icons

Lucide-static 1.58.0 SVG geometry, ISC licence, copied from the canonical local
fixture. The four PNGs were generated at 96×96 using wxWidgets 3.2.12's bundled
SVG rasterizer and PNG encoder (`../wxWidgets/tools/rasterize_icons.cpp`). They
are displayed at 24 DIP; no remote icon/font retrieval occurs. Source SVGs and
licence are retained in `source-icons/` and `notices/` respectively. Rasterization
is an explicit representation difference from the web reference's SVG renderer.

Segoe UI and script/emoji fallbacks come from Windows. No custom TTF rendering is
claimed for RNW 0.85.0's system-collection DirectWrite path.
