A small native host. A local web UI.

One Win32 window hosts Microsoft Edge WebView2. These HTML, CSS, JavaScript and SVG files load directly from the local asset directory.

Vite compiles TypeScript into local JavaScript and external CSS. Greet calls the C++ host through an explicitly enabled test bridge. No Tauri, Rust, server or Go CLI runs here.
