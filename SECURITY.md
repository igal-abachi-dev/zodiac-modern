# Security policy

Zodiac is development software. Security fixes will support **only the latest
stable release**. Development candidates and prereleases are not stable supported
releases; no independently reviewed stable public release is established yet.
Older versions should be upgraded rather than expecting fixes to be backported.

## Private reporting

The maintainer selected **GitHub private vulnerability reporting** for
[igal-abachi-dev/zodiac-modern](https://github.com/igal-abachi-dev/zodiac-modern).
Activation is still unverified; this document
does not claim a working reporting endpoint. Once enabled, use the repository's
Security tab and **Report a vulnerability**. Do not disclose security findings,
private keys, passphrases or confidential messages in public issues.

The project owner, **igal-abachi-dev**, handles report triage and release/security
operations. No response-time SLA is promised. Report affected versions/revisions, scope,
reproduction steps and impact using synthetic data only. Acknowledgement and
coordinated disclosure are handled privately before publishing fixes/advisories.

See [GitHub private reporting setup](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository)
and [the release gate decisions](docs/deployment.md#release-decisions-recorded-2026-10-11).
